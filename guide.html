Quick demo guide

  1. Select Load fictional demo, then review the validation preview.
  2. Import valid rows. Expect 20 valid rows, 2 rejected rows and 2 findings.
  3. Open Example Supplies: two completed INR 5,000 payments share invoice INV-101 but have different payment references.
  4. Mark Under investigation, add a note and leave money at zero.
  5. For a simulated confirmation, enter 5000 as confirmed total and add a fictional evidence reference.
  6. Only after a simulated refund, enter 5000 as recovered with a reference. Mark Resolved when follow-up is complete.
  7. The Demo Cloud increase is INR 2,500 per month, not automatically a saving.
  8. Export the findings report. Clear local data after the demo.

TinyFish

Run the included backend and configure its private environment first. Only approved public page URLs are accepted. A lookup may consume credits. GitHub Pages alone cannot run this server.

Limits

No authentication, shared database or tamper-proof audit log. Browser data can be changed or deleted. Use fictional data only. No actual AI-summary service or trained ML model is included.
